# 🐺 多智能体在线语音狼人杀

## 项目描述
本项目是一款集成大语言模型（LLM）与语音识别（STT）技术的在线多人推理与博弈平台。系统能够将真人玩家的实时语音流转写为文本，并接管房间的自动化发牌与昼夜结算机制。项目核心引入了多智能体（Multi-Agent）架构，赋予 AI 玩家激进、保守、逻辑流等不同性格预设。这些具备独立视角的 AI 能够与真实玩家同局混战，进行自动化的局势推理、伪装发言与投票行动。系统同时记录完整对局日志，并生成 AI 视角的智能复盘报告，致力于打造高度拟真的“人机协同”社交博弈体验。

## 核心技术亮点
### 多智能体AI玩家系统
系统引入 **Multi-Agent 架构**，每个 AI 玩家作为独立 Agent 参与游戏。
每个Agent拥有：
- 独立的游戏记忆（Memory）
- 玩家嫌疑度评估
- 对话理解能力
- 投票与行动策略

AI玩家能够：
- 分析玩家发言
- 推断玩家阵营
- 自动生成发言
- 参与投票与夜晚行动

实现 **AI与人类玩家的实时博弈互动**。

### 实时语音识别与文本转化
玩家在游戏过程中可以通过语音进行交流，系统通过语音识别模块将语音转换为文本，并实时记录到聊天系统中，使得AI玩家能够理解玩家对话并参与推理过程。

### AI辅助游戏复盘
系统将记录完整的游戏日志，包括玩家发言，投票记录，夜晚行动，游戏阶段变化等内容，并生成 **AI推理分析报告**，用于复盘和策略分析。
