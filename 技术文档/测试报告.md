## 1. 概述

### 1.1 系统需求概述

本系统是基于 Web 的多智能体在线语音狼人杀游戏平台，采用前后端分离架构实现，支持玩家通过浏览器完成房间组织、实时对局、语音交互以及 AI 智能对战等功能。系统在传统狼人杀规则基础上，引入 AI Agent 玩家与智能复盘能力，使系统不仅能够支持真人玩家对局，还能够支持 AI 参与推理、发言、投票及赛后分析。

系统核心目标包括：

* 支持多人玩家稳定完成完整狼人杀游戏流程；
* 保证游戏状态在不同客户端之间实时同步；
* 支持狼人、预言家、女巫、猎人等角色技能的正确执行；
* 支持昼夜阶段切换、投票放逐及胜负判定等核心规则；
* 支持 AI 玩家根据游戏上下文进行行为决策；
* 支持对局日志记录与 AI 智能复盘分析；
* 支持语音输入、语音转写及语音播放等扩展交互能力。

### 1.2 系统设计与实现概述

本系统采用前后端分离架构。当前仓库中的主游戏客户端位于 `client/`，后端位于 `server/`，复盘展示前端位于 `replay_frontend/`，复盘 Python 服务位于 `ai_replay_service.py` 与 `replay_ai_backend/`。后端主体是基于 Koa 的 Node.js 应用，启动入口为 `app.js`，通过 `server/application/index.js` 和 `loader.js` 自动装载 Controller、Service、Middleware、Sequelize Model、定时任务和 WebSocket 服务。

后端采用 Controller、Service、Model 分层组织：Controller 负责路由入参校验和统一响应，Service 负责游戏规则、AI 调度、语音服务、复盘服务等业务逻辑，Model 通过 Sequelize 映射 MySQL 表结构。REST API 由 `server/routes/index.js` 统一注册；WebSocket 由 `nodejs-websocket` 监听 `6003` 端口，并以 `/lrs/{roomId}` 房间路径推送阶段变化、倒计时、刷新、游戏结束和实时语音相关消息。
